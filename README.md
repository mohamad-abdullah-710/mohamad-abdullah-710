### 📦 [ReorderAI — Dream Data](https://github.com/mohamad-abdullah-710/dream-data-reorderai)

> An AI agent that helps businesses avoid stock shortages **before** they happen.

ReorderAI watches live risk signals (like weather at supplier locations), compares them with inventory,
predicts which products will run out, and drafts **risk-scored purchase orders** that a human approves.

- 🧠 Monitor agent built with **Google ADK + Gemini**
- 🗺️ Web dashboard: supplier map, risk alerts, inventory runway, 7-day weather
- 🔮 What-if simulator and AI assistant chat
- 📱 Mobile view in **English, Turkish and Arabic** with light/dark mode
